# 癒し処 結月 Webサイト

二子玉川の架空ドライヘッドスパ専門店「癒し処 結月」の商用サイト想定デモです。React、Vite、TypeScript、Tailwind CSSで制作しています。

## 開発

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## テスト

```bash
npm test -- --run
```

## 本番ビルド

```bash
npm run build
```

## 本番ビルドのプレビュー

```bash
npm run preview
```

## ご注意

- 店舗、所在地、セラピストなどの情報はすべて架空です。
- 予約フォームは入力・確認・完了画面を体験するためのデモで、入力内容を外部へ送信・保存しません。
- LINE相談ボタンもデモ表示で、外部サービスには接続しません。
- 実店舗として公開する場合は、店舗情報、予約先、法的表記、連絡先を実際の内容へ差し替えてください。
