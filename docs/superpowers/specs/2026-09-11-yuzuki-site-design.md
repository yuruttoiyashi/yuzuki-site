# ドライヘッドスパ専門店「癒し処 結月」Webサイト設計仕様書

作成日：2026年9月11日

## 1. 目的

30〜50代の働く女性に向けて、PC・スマートフォン疲れ、眼精疲労、首肩の疲れ、睡眠不足、日々のストレスに寄り添い、安心して予約へ進める商用サイトを制作する。

単なるLPではなく、情報を探しやすい複数ページ構成とし、実在する個人経営サロンがそのまま公開できる品質を目指す。

## 2. ブランド設計

- 店名：癒し処 結月（ゆづき）
- 英字表記：YUZUKI DRY HEAD SPA
- キャッチコピー：がんばる毎日に、深い休息を。
- 対象：30〜50代を中心とした働く女性
- 印象：和モダン、上質、静けさ、深い休息、女性らしいが甘すぎない
- 避ける表現：和風テンプレート、旅館・和食店のような演出、筆文字の多用、大量のカード、過剰な装飾・グラデーション

「和」は障子・竹・筆文字などの直接的な記号ではなく、余白、素材感、静かな色、光と陰影で表現する。

## 3. ビジュアル方針

採用案：A「余白と静けさ」

### 色

- 背景：生成り `#F3EEE5`
- 主要文字・濃色背景：墨色 `#292725`
- 補助色：くすみブラウン、石のグレー
- アクセント：真鍮を思わせる控えめなゴールド
- 白ではなく生成りを基調にし、暗色は章の切り替えとCTAに限定する

### タイポグラフィ

- 見出し：細身で品のある日本語明朝体
- 本文・操作要素：可読性の高い日本語ゴシック体
- ロゴ：筆文字を使わず、「癒し処 結月」を明朝体で端正に表現
- 小さな英字を補助的に使うが、日本語の理解を妨げない

### レイアウト

- 大きな写真と十分な余白を中心にする
- 写真と文章を少しずらした非対称構成を採用する
- 写真が大きい章、文章を静かに読ませる章、墨色背景の章を交互に配置する
- カードは必要な比較情報に限定し、ページ全体をカード一覧にしない
- ボタンは角を丸くしすぎない端正な長方形とする

### 写真

結月専用として、同一の内装・人物・色調に見える画像を3点制作する。

1. ファーストビュー用：木・石・リネン・間接照明を感じる静かな施術室
2. 施術紹介用：女性客へのドライヘッドスパ施術中の手元
3. サロン紹介用：自然体の女性セラピストと落ち着いたサロン空間

広告写真のような過度な笑顔や白く明るすぎる内装を避け、実在感と静けさを優先する。

## 4. ページ構成

### TOP `/`

1. ファーストビュー
   - 「癒し処 結月」
   - 「がんばる毎日に、深い休息を。」
   - 大きな施術室写真
   - 「予約する」CTA
2. コンセプト
   - 忙しい毎日から意識的に離れ、頭と心を休める時間を提案
3. 悩みへの共感
   - 目の重さ、首肩のこわばり、眠りの浅さ、思考が止まらない感覚などを自然な言葉で表現
4. 結月の特徴
   - 一人ずつの完全予約制
   - 頭だけでなく首肩まで考えた施術
   - 音・光・香りを抑えた休息空間
5. 人気メニュー
   - 「巡り − 首肩・眼精疲労ケア 75分」を中心に紹介
6. 施術の流れ
   - 来店、カウンセリング、施術、アフターティー・会計
7. セラピスト紹介
8. サロン空間
9. FAQ
10. 店舗・アクセス情報
11. 最終予約CTA

### メニュー `/menu`

3コースについて、料金、時間、施術範囲、向いている悩みを掲載する。「巡り 75分」を人気コースとして控えめに強調する。

- 結月 ベーシック：60分 / 7,700円
- 巡り − 首肩・眼精疲労ケア：75分 / 9,500円
- 深眠 − プレミアム：90分 / 11,800円

追加料金や架空のオプションは設けない。表示価格は税込と明記する。

### サロン `/salon`

- 施術への考え方
- サロン空間と衛生面
- オーナーセラピスト紹介
- 初回来店の流れ
- 店舗情報とアクセス
- 完全予約制・女性専用・住所案内方法

### 予約 `/reserve`

- 予約フォーム
- LINE相談への補助導線
- 予約前の注意事項
- キャンセル・変更案内
- デモサイトであることの明記

## 5. 架空店舗設定

- 形態：女性専用・完全予約制のプライベートサロン
- 所在地：東京都世田谷区玉川2丁目（建物名・部屋番号は予約確定後に案内）
- 最寄り：東急田園都市線・大井町線 二子玉川駅から徒歩5分
- 営業時間：10:00〜20:00（最終受付18:30）
- 定休日：火曜日・不定休
- 支払い：現金、主要クレジットカード、交通系電子マネー
- 駐車場：専用駐車場なし。近隣コインパーキングを案内
- セラピスト：水城 紗月（みずき さつき）

実在店舗と誤認させないため、サイト内のフッターと予約完了画面にポートフォリオ用デモサイトであることを明記する。

## 6. 予約体験

採用方式：サイト内フォーム＋LINE相談の併設

フォームは外部送信や保存を行わないデモ仕様とし、次の3段階で動作する。

1. 入力
   - コース
   - 希望日
   - 希望時間
   - 名前
   - メールアドレス
   - 電話番号
   - 悩み・要望（任意）
   - 注意事項への同意
2. 確認
   - 入力内容を一覧で確認
   - 「修正する」「この内容で送信する」
3. 完了
   - 受付メッセージ
   - 「デモサイトのため予約は確定していません」の明記
   - TOPへ戻る導線

必須項目、メール形式、電話番号、過去日付を検証する。エラーは該当項目の近くに日本語で表示し、色だけで判別させない。送信失敗を装う機能や実データ保存は設けない。

## 7. 共通UX

- スマートフォンを最優先に設計
- 共通ヘッダーとフッター
- デスクトップは横並びナビゲーション
- スマートフォンは開閉式メニュー
- スマートフォン画面下に固定の予約ボタン
- メニュー名、時間、料金が早い段階で分かる
- 初めての個人サロン利用者が不安にならない説明順序
- ホバーは色・位置がわずかに変わる程度
- スクロール演出はゆっくりしたフェードと小さな上移動に限定
- `prefers-reduced-motion` 設定時は不要な動きを停止
- 現在のページがナビゲーションで分かる

## 8. 技術設計

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- 静的サイトとして構成し、データベースや認証は使用しない

### 主な部品

- `SiteHeader`：共通ナビゲーションとスマホメニュー
- `SiteFooter`：店舗情報、ページリンク、デモ表記
- `FixedReserveButton`：スマートフォン用固定CTA
- `SectionHeading`：章見出し
- `PageHero`：下層ページの導入
- `MenuList` / `MenuItem`：料金・施術内容
- `FlowSteps`：来店から退店までの流れ
- `FaqAccordion`：FAQ
- `SalonInfo`：店舗情報
- `ReservationForm`：入力・確認・完了状態
- `Reveal`：控えめなスクロール表示

メニュー、FAQ、店舗情報はデータとして一元管理し、TOPと個別ページで同じ内容を再利用する。

## 9. アクセシビリティ

- 本文は原則16px以上、操作ラベルは14px以上
- 背景と文字のコントラストを確保
- 200%の文字拡大でも内容と操作を維持
- キーボード操作と視認できるフォーカス表示
- スマホのタップ領域を十分に確保
- 画像に適切な代替テキストを付ける
- フォームのラベルとエラーを関連付ける
- FAQとスマホメニューの開閉状態を支援技術へ伝える

## 10. SEO・メタ情報

- 各ページに固有のタイトルと説明文を設定
- 見出し階層を正しく構成
- 店名、ドライヘッドスパ、二子玉川、眼精疲労、首肩疲れなどを不自然にならない範囲で文章へ含める
- SNS用画像は今回の範囲に含めない

## 11. 検証基準

- TOP、`/menu`、`/salon`、`/reserve` が直接表示できる
- 共通ナビゲーションとCTAから正しいページへ移動できる
- 3コースの時間・料金・説明が全ページで一致する
- 予約フォームの入力、確認、修正、完了が動作する
- 未入力、形式不正、過去日付のエラーが表示される
- 個人情報が外部送信・保存されない
- スマートフォンで横スクロールや文字切れがない
- 固定予約ボタンが主要コンテンツを隠さない
- キーボード操作とフォーカス表示が機能する
- 動きを減らす設定が反映される
- 制作画像が読み込まれ、代替テキストが設定される
- 本番用ビルドが成功する

## 12. 今回含めないもの

- 実際の予約受付・メール送信
- 顧客情報の保存
- オンライン決済
- 会員登録・ログイン
- 管理画面
- ブログ・お知らせ更新機能
- SNS用OG画像の新規制作

これらは実店舗向けへ展開する際に追加できるよう、予約フォームとコンテンツを独立した部品として設計する。
